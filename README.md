# 🌍 Personalized Adventure Guide

A Python-based travel planning application that helps users organize their trips based on travel preferences, budget, and trip duration. It provides personalized destination suggestions, estimated travel expenses, recommended activities, and packing checklists.

## ✨ Features

* 🏔️ **Destination Recommendations:** Suggests destinations based on Mountain or Beach preferences.
* 💰 **Budget Categorization:** Classifies trips into Luxury, Comfortable, Budget-Friendly, and Low-Budget categories.
* 🧮 **Trip Cost Calculator:** Estimates total expenses based on trip duration, number of travelers, and daily budget per person.
* 🎯 **Activity Recommendations:** Provides activity suggestions according to the selected destination.
* 🎒 **Packing Checklist:** Offers useful packing suggestions for different travel experiences.
* 🔄 **Multiple Trip Planning:** Allows users to plan multiple trips in one session.
* ⚠️ **Input Validation:** Handles invalid inputs and prevents incorrect calculations.

## 🚀 Getting Started

### Prerequisites

* Python 3.x installed on your system.
* Git installed on your system (optional, for cloning).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Anshika-Srivastava-28/Personalized-Adventure-Guide.git
```

**2. Navigate to the project directory**

```bash
cd Personalized-Adventure-Guide
```

**3. Run the application**

```bash
python adventure_guide.py
```

## 💡 How It Works

1. Enter your name.
2. Select your preferred travel type: Mountain or Beach.
3. Enter the number of travel days.
4. Enter the number of travelers.
5. Provide your daily budget per person.
6. Receive your estimated trip cost and budget category.
7. Explore recommended activities and packing suggestions.
