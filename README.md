# 🌍 Personalized Adventure Guide

A Python-based travel recommendation application that helps users plan their trips according to their travel preferences, budget, and trip duration.

## ✨ Features

* 🏔️ **Destination Recommendations:** Suggests destinations based on Mountain or Beach preferences.
* 💰 **Budget Categorization:** Classifies trips into Luxury, Comfortable, Budget-Friendly, and Low-Budget categories.
* 🧮 **Trip Cost Calculator:** Estimates total trip expenses based on duration, number of travelers, and daily budget.
* 🎯 **Activity Recommendations:** Suggests activities according to the selected destination type.
* 🎒 **Packing Checklist:** Provides useful packing suggestions.
* 🔄 **Multiple Trip Planning:** Allows users to plan multiple trips in one session.
* ⚠️ **Input Validation:** Handles invalid inputs and prevents incorrect budget calculations.

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

* Python 3.x installed on your system.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Personalized-Adventure-Guide
   ```

3. Run the Python application:

   ```bash
   python adventure_guide.py
   ```

## 💡 How It Works

1. Enter your name.
2. Select your preferred travel type (Mountain or Beach).
3. Enter the number of travel days.
4. Enter the number of travelers.
5. Provide your daily budget per person.
6. Get your estimated trip cost, budget category, recommended activities, and packing checklist.
